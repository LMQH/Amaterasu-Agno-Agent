# 调研索引

**性质**：本目录是独立的调研仓库，只提供事实、候选评估与源码核查。

- **仅供参考，不承诺作为实现基线。** 这里的结论不构成对任何实现的约束；只有被转述或复制进设计文档的结论才生效。
- **设计文档不引用本目录。** 架构与模块设计文档里不出现本目录的链接或路径；需要用到结论时，把结论本身写进设计文档。
- **治理独立。** 本目录按主题维护，不代表产品状态；代码或设计变更时，不强制同步本目录。
